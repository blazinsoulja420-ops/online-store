# Phase 1 Acceptance Criteria

A Phase 1 foundation is acceptable only when:

1. Known requirements are represented by code or explicit interfaces.
2. Safety/security/business invariants have automated tests where deterministic.
3. Shared capabilities are referenced, not copied wholesale.
4. No production secret is committed.
5. No live spend, deployment, or destructive action is enabled.
6. CI can run the repository's basic validation/test command.
7. README/docs explain local development and remaining blockers.
8. UNKNOWN requirements remain explicitly unknown rather than silently assumed.
